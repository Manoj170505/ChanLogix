# ChanLogix

ChanLogix - A Global Intelligence Logistics Platform Across World.

High-precision international express courier, ocean/air cargo forwarding, automated warehousing, and intelligent customs clearance connecting over 150 countries.

## Tech Stack
- React 19 + Vite
- Tailwind CSS
- Lucide React & React Icons
- Cobe 3D Interactive WebGL Globe

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
